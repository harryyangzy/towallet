# ToWallet

Non-functional iOS app mockup based on the Figma designs for adding and managing Wallet cards.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Screens

- **Add a Card** — upload image, edit card info, colour slider, live card preview
- **Manage Wallet** — list of saved cards

Design system: `#212121` background, `#FF9B5B` accent, `#D2D2FF` upload chip, Be Vietnam Pro.
